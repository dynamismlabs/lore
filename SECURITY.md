# Security

Report vulnerabilities privately through [GitHub's vulnerability reporting form](https://github.com/dynamismlabs/lore/security/advisories/new).
Include the affected version, reproduction steps, and impact. Do not include real memories, credentials,
or family photos, and do not open a public issue for an undisclosed vulnerability.

Security fixes target the latest version on the default branch. Self-hosters should keep their
deployment up to date.
